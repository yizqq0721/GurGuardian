## 2. 本地构建

### 2.1 后端

```powershell
cd <仓库根目录>
mvn -B "-Dmaven.test.skip=true" clean package
Get-FileHash pet-web\target\pet-web-0.0.1-SNAPSHOT.jar -Algorithm SHA256
```

- **引号必须加**：PowerShell 会把 `-Dmaven.test.skip=true` 拆成两个参数，Maven 报 `Unknown lifecycle phase ".test.skip=true"`。
- **先查占用**：若 `clean` 报 `Failed to delete ...jar: 另一个程序正在使用此文件`，说明有本地测试实例还开着：

```powershell
Get-CimInstance Win32_Process -Filter "Name='java.exe'" |
  Select-Object ProcessId, CommandLine
# 确认该实例已无响应后再终止（例：curl 本地 8080 超时）
Stop-Process -Id <PID> -Force
```

### 2.2 前端

```powershell
cd fur-guardian-front
npm run build
```

- 沙箱环境下 `vite build` 可能报 `spawn EPERM`（esbuild 需要开子进程并接管管道），改为免沙箱执行即可。
- 产物入口文件名带 hash，可在切换后用它确认新版本是否生效。

```bash
# 5.3 切换（mv 是原子的，避免出现半个目录）
mv /opt/furguardian/web /opt/furguardian/web.old-$ts
mv /opt/furguardian/web.new /opt/furguardian/web

```

注意：`docker compose config -q` 只做校验，**不会**重建容器；本次没有改任何容器参数，所以不需要 `docker compose up -d`。

## 9. 本次踩到的坑与对策

| 现象 | 原因 | 对策 |
| --- | --- | --- |
| 命令报 `grantWrite(<工作区>)` | 工作区目录缺当前用户写入权限 | 用 ACL 诊断脚本补齐权限，改前备份、可回滚 |
| `Unknown lifecycle phase ".test.skip=true"` | PowerShell 拆分未加引号的 `-D` 参数 | `"-Dmaven.test.skip=true"` 加引号 |
| `Failed to delete ... jar`、`repackage` 无法重命名 | 本地僵死 `java -jar` 进程锁住产物 | 确认无响应后 `Stop-Process` 清掉 |
| 前端构建 `spawn EPERM` | 沙箱禁止子进程管道 | 免沙箱执行构建 |
| `$'\r': command not found` | PowerShell here-string 的 CRLF 传给了远端 bash | 脚本先 `.Replace("`r","")` 再走 `ssh bash -s` |
| 上传后服务起不来 | 传输截断 | 先传 `.new` → 校验 sha256 → `mv` 切换 |
| 线上代码比分支新 | 构建时工作区有未提交改动 | 上线前先 `git status`，确认哪些改动要一起上 |

## 14. 2026-10-20 22:00 手机端宠物卡片切换修复（仅前端）

> 类型：**纯前端增量发布**（未重启后端）
> 触发问题：手机端卡片轮播轻微滑动就从第 1 张跳到第 7 张。

**根因**：
- `--center-w` 在手机端是 `calc(100vw - 32px)`，`parseFloat` 解析失败得 `NaN` → 步长 0
- `--side-w` 手机端为 `0px` → 反方向步长也是 0
- `拖动距离 / 0 = Infinity` → 步数被 clamp 直接落到首/尾
- 隐藏卡仅设 `opacity:0`，仍保留 34px padding/border，后续卡片整体右移

**修复**：
- 步长改为优先读声明值，解析不出时测量当前激活卡 `offsetWidth`
- 手机端（`--side-w === 0`）一次手势最多切一张，阈值 20%
- 手机端拖动距离限制为卡宽的 35%（最小 64px），避免整卡拖出视口
- 隐藏卡 `width/padding/border-width` 一并归零
