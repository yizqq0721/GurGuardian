# FurGuardian 前端响应式改造说明

## 1. 范围与断点

- **桌面端（≥ 768px）**：完全沿用原有布局、字号、间距与交互，不做任何视觉改动。
- **移动端（< 768px）**：统一使用 `@media (max-width: 767.98px)` 生效，覆盖 320px–767px 的窄屏设备。
- 所有响应式代码块均以 `/* ===== 响应式新增：移动端（<768px） ===== */` 或 `/* ---------- 响应式新增 ---------- */` 注释标注，便于检索与回滚。
- **未改动**：后端接口、路由、Pinia store、API 调用、业务计算与页面 JS 逻辑。仅新增移动导航所需的 UI 状态。

## 2. 全局改造

### 2.1 视口与样式入口

- `index.html`
  - 增加：
    ```html
    <meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no" />
    ```
- `src/main.ts`
  - 在 `index.css` 之后引入 `responsive.css`，保证移动端覆盖规则最后生效。

### 2.2 新增 `src/styles/responsive.css`

仅包含移动端规则：

- `html, body { overflow-x: hidden; }`，杜绝页面级横向滚动。
- `img { max-width: 100%; height: auto; }`，所有图片自适应容器。
- 缩小移动端标题字号：`--fg-text-display / h1 / h2 / h3 / lead`，正文与辅助字号保持可读。
- 收紧容器间距：`.fg-page`、`.fg-card`、`.fg-split`、`.fg-kv`、`.fg-metric-row`。
- 触摸目标统一提升到 **44px**：
  - `.el-button`、`.el-button--small`、`.el-input__wrapper`、`.el-select__wrapper`、`.el-radio-button__inner`、`.el-checkbox`、`.el-radio`。
  - 输入框字号设为 16px，避免 iOS 聚焦时自动放大页面。
- 弹层适配：
  - `.el-dialog` 宽度改为 `calc(100vw - 32px)`，最大 560px，内部可滚动。
  - `.el-message-box`、`.el-message`、`.el-drawer` 同步限制为视口宽度。
  - `.el-pagination` 允许折行并隐藏“每页条数 / 跳页”，避免撑破窄屏。
- 全局 `box-sizing: border-box` 原项目已存在（`src/styles/index.css`），本次确认无需重复添加。

## 3. 导航栏：折叠汉堡菜单

文件：`src/layouts/AppLayout.vue`

- 新增 44×44 汉堡按钮（`Menu` / `X` 切换），桌面端默认 `display: none`。
- 新增移动端折叠面板：遮罩 + 纵向菜单，覆盖我的宠物、食品库、提醒、周报、知识库、设置、退出登录。
- 交互补充：
  - 点击菜单项后自动关闭；
  - 路由变化自动关闭；
  - `Escape` 关闭；
  - 视口回到 ≥768px 时自动关闭；
  - 展开时锁定 `body` 滚动，关闭时恢复。
- 顶栏在移动端收紧：品牌字号 16px、隐藏桌面横向导航与用户名入口、宠物切换器限制到 104px；超窄屏（<360px）隐藏品牌文字。

## 6. 溢出与触摸目标处理

- 两张最宽的表格（食品库、周报）在移动端替换为卡片列表，避免横向滚动。
- 所有固定宽度均补充移动端覆盖：食品搜索 260px、知识库会话栏 300px / 筛选 120px、建档卡片 560px / 输入 160px、提醒时间选择 160px、顶栏宠物切换 160px。
- 长文本统一使用 `overflow-wrap: anywhere` / `min-width: 0` / `flex-wrap`：长公式、来源、宠物名、任务名、规则详情等。
- 触摸目标例外：
  - BCS 9 分制刻度为保持一屏可点，按列宽压缩；
  - 宠物卡圆形打卡键保持 22px 视觉，点击热区扩至 44px；
  - 纯文本链接在布局允许处提升到 44px 行高。
